# ADR 9. Database Triggers for Automated Auditing and Aggregations

* **Status**: Accepted
* **Date**: 2026-08-13

## Context
Securing tracking requirements (such as logging user table edits and auto-incrementing top-searched tables) must execute reliably regardless of server-side state or API failures.

## Decision
We chose native PostgreSQL Triggers (`CREATE TRIGGER`) executing PL/pgSQL procedures. Triggers handle transaction logs on insertion, deletion, and updates automatically on key tables.

## Consequences
Immutable security logs are written directly at the engine layer. Incremental aggregations (like player search counters) run instantly without application overhead.
