# ADR 6. Arrow Functions for Backend Implementations

* **Status**: Accepted
* **Date**: 2026-08-13

## Context
We need a consistent syntax definition for asynchronous API route handlers, services, and utility helpers across the Express.js backend.

## Decision
We chose arrow functions (`const fn = async (req, res) => {}`) for all backend implementations. This establishes a clean, modern, and uniform coding style throughout our server-side codebase.

## Consequences
Enhanced readability and style consistency across controllers, routers, and configurations, aligning backend Javascript with modern ES6+ standards.
