# ADR 2. RBAC and JWT Authentication for Security

## Context

The platform needs to support tiered user access levels (Free search limits, PRO premium access, and Admin system dashboards) while securing REST API endpoints and user routing.

## Decision

We chose stateless JWT Authentication combined with custom Role-Based Access Control (RBAC) middlewares. User role and tier claims are carried securely in tokens and validated on every request.

## Consequences

API endpoints and routing are secure without maintaining server-side session state. Menu visibility and route access automatically reflect the current user's role.
