# ADR 3. React and Vite for Single Page Application

## Context

The platform requires a fast, responsive user interface to display interactive charts, reports, and search fields without full-page reloads.

## Decision

We chose React combined with Vite as the build tool. This enables component-based modular UI design, rapid Hot Module Replacement (HMR) during development, and highly optimized production builds.

## Consequences

Faster initial load times, a highly modular frontend structure (components split by folders), and dynamic, responsive interface updates for our dashboards.
