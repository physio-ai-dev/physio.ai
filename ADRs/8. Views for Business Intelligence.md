# ADR 8. Database Views for Business Intelligence

* **Status**: Accepted
* **Date**: 2026-08-13

## Context
Aggregating statistical data (such as monthly injuries, player popularity ranks, and user search histories) across multiple related tables requires complex, resource-heavy SQL joins.

## Decision
We chose PostgreSQL database-level Views (`CREATE VIEW`) to modularize aggregations. These views run on the database layer and isolate complex joining logics away from the Express.js application controllers.

## Consequences
Faster execution of executive queries, decoupled data structures, and simplified TypeORM consumption through straightforward read operations on pre-aggregated views.
