# ADR 7. Recharts for Data Visualization

* **Status**: Accepted
* **Date**: 2026-08-13

## Context
The platform needs to output clean, interactive, and responsive visualizations for metrics, user adoption distribution, and search engine logs inside the Admin Dashboard.

## Decision
We chose Recharts as our charting library. It utilizes SVG graphics, offers declarative React components, and integrates with the Dark Theme and responsive GlassCard layouts.

## Consequences
Provides smooth animations, highly interactive tooltips (with custom subtle cursors), and layouts that scale dynamically across both desktop and mobile viewports.
