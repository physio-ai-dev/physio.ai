# ADR 10. Database Indexes for Search Optimization

* **Status**: Accepted
* **Date**: 2026-08-13

## Context
High-frequency queries on fields like email validation, user search lookups, and player name queries degrade performance as data scales.

## Decision
We chose PostgreSQL database indexes (`CREATE INDEX` / constraints) automatically configured via TypeORM unique columns and primary keys. These indexes speed up data lookups on filtered columns.

## Consequences
Retrieval times for players and users remain low. Search latency is minimized, preserving system performance under high traffic.
