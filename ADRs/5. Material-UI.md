# ADR 5. Material-UI for Component Styling

## Context

We need a consistent, visually pleasing components kit (inputs, grids, charts wrappers, chips, dialogs) that supports dark mode and responsive design out of the box.

## Decision

We chose Material-UI (MUI) as the primary UI library. We customize its theme object with a bespoke dark layout matching our premium visual guidelines.

## Consequences

Design implementation times are reduced. Interactive components are fully accessible and adapt gracefully to different screen sizes.
